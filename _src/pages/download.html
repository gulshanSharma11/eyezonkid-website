Installation help

Stuck while installing?

Quick fixes for the most common questions. Still stuck? Write to support@eyezonkid.com.

My Mac says the app “can't be opened”

Open System Settings → Privacy & Security, scroll down and click Open Anyway next to Eyezonkid. You only need to do this once.

Windows shows a blue “Windows protected your PC” screen

Click More info, then Run anyway. This can appear for newly released apps while Windows builds trust in the installer.

Which app goes on my child's phone?

The computer apps are for you, the parent. Your child's phone uses the Eyezonkid mobile app — install it on their device and pair it with the one-time code shown in your parent app.
